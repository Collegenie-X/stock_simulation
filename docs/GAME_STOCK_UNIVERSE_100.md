# 종목 유니버스 100선 — 실재 한국 상장사 기반

> **기획 우선 원칙**: 코드 짜기 전에 "어떤 회사들이 등장하고, 각 회사가 어떤 성격이고, 어떤 사건에 어떻게 반응하는지" 를 먼저 못 박는다.
> 이 문서는 게임 시계열의 **재료 카탈로그**.

## 0. 먼저 함께 정해야 할 기획 질문 6개

코드로 들어가기 전, 답이 정해져야 할 것들. 답에 따라 구현 방식이 갈린다.

| # | 질문 | 옵션 | 영향 |
|---|---|---|---|
| Q1 | 한 판에 등장 종목 수는? | **5종 / 8종 / 10종** | UI 복잡도, 한 판 길이 |
| Q2 | 종목명을 실명으로 쓸지, 가공명으로 쓸지? | 실명(몰입) / 가공(법적 안전) | 법적 리스크 vs 몰입감 |
| Q3 | 100종 풀 → 매판 N종 추출 방식? | 완전 랜덤 / **테마 매칭** / 난이도별 풀 | 매판 다양성, 학습 효과 |
| Q4 | 종목 캐릭터 분포는 매판 동일? | **고정 비율** (블루1/성장2/변동1/작전1) / 랜덤 | 난이도 일관성 |
| Q5 | 실제 가격대로 시작할지, 정규화할지? | 실가격 / **1만~10만원으로 정규화** | UI 가독성 |
| Q6 | 섹터 ETF 노출은? | 개별주만 / ETF 1~2종 추가 | 분산 학습 |

> **추천 디폴트**: Q1=5종 · Q2=실명 · Q3=테마 매칭 · Q4=고정 비율 · Q5=정규화 · Q6=개별주만 (1차 버전)

## 1. 종목 캐릭터 5종 (재확인)

| 캐릭터 | 변동성 | 추세 | 함정 빈도 | 학습 포인트 |
|---|---|---|---|---|
| 🐢 **블루칩** | ±1% | 완만 상승 | 거의 없음 | 인내, 분산의 가치 |
| 🐂 **성장** | ±3% | 강한 상승 후 조정 | 가짜 돌파 자주 | 추세 추종, 익절 타이밍 |
| 🎢 **변동** | ±5% | 등락 반복 | 데드캣 자주 | 손절 규율 |
| 🦂 **작전** | ±8% | 점진 상승 → 폭락 | 작전 패턴 확정 | 거래량 의심, 욕심 절제 |
| 💀 **부실** | ±3% | 완만 하락 | 호재 페이크 | 가치 함정 식별 |

매판 권장: **블루 1 + 성장 2 + 변동 1 + 작전/부실 1**

## 4. 매판 종목 추출 알고리즘

```ts
function pickMatchStocks(seed: number, theme?: Theme): Stock[] {
  const rng = seedRandom(seed)

  // 1) 캐릭터 비율 강제
  const result: Stock[] = []
  result.push(pickRandom(BLUECHIP_POOL, rng))            // 24종 중 1
  result.push(pickRandom(GROWTH_POOL, rng))              // 14종 중 1
  result.push(pickRandom(GROWTH_POOL, rng, exclude=result))  // 1 더
  result.push(pickRandom(VOLATILE_POOL, rng))            // 49종 중 1
  result.push(pickRandom([...TRAP_POOL, ...DECLINE_POOL], rng))  // 작전 6 + 부실 7

  // 2) 섹터 다양성 보장 (옵션)
  // 같은 섹터에서 3종 이상 안 나오게

  // 3) 테마 모드 (옵션)
  // theme="중동전쟁" → 방산 + 정유 + 항공 + 환율수혜 + 함정 1
  if (theme) return pickByTheme(theme, rng)

  return result
}
```

| **M** | 1~10조 | 20,000~80,000원 | 중형주 |
| **S** | 1조 미만 | 5,000~30,000원 | 소형주 (변동성 ↑) |

## 7. 종목별 베이스 차트 패턴 (시계열 생성기 입력값)

각 종목은 **이벤트 영향 외에 자체 추세**를 가진다. 시드별로 생성:

```ts
interface StockProfile {
  id: string
  ticker: string
  name: string
  character: "bluechip" | "growth" | "volatile" | "trap" | "decline"
  sector: string
  marketCap: "XL" | "L" | "M" | "S"

  // 차트 생성 파라미터
  baseAmplitude: number      // 사인파 진폭 (0.05~0.20)
  basePeriod: number         // 사인파 주기 (15~30턴)
  basePhase: number          // 위상 (랜덤)
  trend: number              // 장기 드리프트 (-0.001~+0.003/턴)
  noiseLevel: number         // 노이즈 (0.005~0.015)

  // 함정 설정 (작전형만)
  trapPattern?: {
    triggerTurn: number      // 함정 발동 턴
    pumpDays: number         // 펌핑 기간
    pumpRate: number         // 펌핑율 (+30~50%)
    dumpRate: number         // 덤핑율 (-50~70%)
  }

  // 이벤트 민감도
  eventSensitivity: { [eventId: string]: number }  // -2 ~ +2 배수
}
```

캐릭터별 기본값:

| 캐릭터 | amplitude | period | trend | noise |
|---|---|---|---|---|
| 🐢 블루칩 | 0.05 | 25 | +0.001 | 0.005 |
| 🐂 성장 | 0.10 | 20 | +0.002 | 0.010 |
| 🎢 변동 | 0.12 | 18 | 0 | 0.012 |
| 🦂 작전 | 0.08 | 22 | +0.003 → 폭락 | 0.008 |
| 💀 부실 | 0.06 | 25 | -0.001 | 0.008 |

## 9. 토론 포인트 — "이거 어떻게 할까요?"

### 💬 토론 1. 실명 vs 가공명
**실명 사용**의 장점: 몰입감, 학습 효과 (실제 사건 매핑)
**실명 사용**의 위험: 회사 명예훼손 가능성 (특히 부실/작전 분류)

> 💡 절충안: "교육 목적, 실제 데이터와 다를 수 있음" 면책 조항 + 작전/부실 분류는 회사명 살짝 변형 (예: "에코프로" → "K-에코프로")

### 💬 토론 2. 시총 등급의 의미
시총 XL/L/M/S를 **가격대 차이**로만 쓸지, **변동성·뉴스 빈도**도 다르게 할지?

> 💡 추천: XL은 변동성 작고 뉴스 자주, S는 변동성 크고 뉴스 가끔

### 💬 토론 3. 종목 보유 한도
한 종목에 자산 80% 이상 투입 시 "올인 경고" — 이미 디자인됨. 한도를 50%로 더 강하게?

> 💡 추천: 50% 초과 시 경고 토스트, 80% 초과 시 모달 + 점수 페널티

### 💬 토론 4. 매판 N종 — 5/8/10
- 5종: 한 판 짧고 깔끔, 분산 학습 약함
- 8종: 균형
- 10종: 분산 학습 좋지만 화면 복잡

> 💡 추천: **튜토리얼 3종 / 표준 5종 / 하드 8종** (난이도별 차등)

### 💬 토론 5. 함정 회피 가능성
작전주(에코프로 모델)는 **무조건 한 종목 등장**. 안 사면 회피 = 정답?

> 💡 추천: 작전주는 **초반엔 매력적 차트** (못 사면 후회) → 후반 폭락 → "사도 빠져나오는 게 답" 형태로 설계
