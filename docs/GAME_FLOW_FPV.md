# 게임 플로우 — 1인칭 시점 구조도

> 플레이어가 앱을 켜고 한 판을 끝낼 때까지 **"내가 보는 화면 / 내가 느끼는 감정 / 내가 하는 결정"** 을
> 시간 순서대로 따라가는 구조도. 스타크래프트 한 판처럼.

**선택지의 결과**:

- **관망**: 평균. 감각 +10.

## 12. 데이터 흐름 — 1인칭 시점에서 안 보이는 뒷단

```
플레이어 시점          │       시스템 뒷단
─────────────────────────────────────────────────
[시작] 누름           │  → seed = Date.now()
                      │  → buildScenario(seed)
                      │  → 5종목 캐릭터 배정
                      │  → Act별 이벤트 14개 추출
                      │  → 시계열 생성 + 이벤트 주입
                      │  → currentRun_v1 저장
                      │
[매수 10주]           │  → 결정 평가
                      │  → senseScore += 30
                      │  → holdings 업데이트
                      │  → decisionLog 추가
                      │  → currentRun_v1 갱신
                      │
[Act 2 진입]          │  → guides = OFF
                      │  → eventTrigger(act2)
                      │  → 차트 변동성 계수 ↑
                      │
[블랙스완 발생]       │  → applyEvent(act3-01)
                      │  → 모든 종목 -8% 갭다운

                      │
[게임 종료]           │  → 등급 산정 (Sense + Profit)

                      │  → currentRun_v1 → recentRuns 이동
                      │  → 리플레이 데이터 보존
```
