## 🌊 파도 타는 5대 원칙

각 이벤트별 "파도 타는 법"을 읽기 전에 공통 원칙부터:

1. **첫 충격은 과잉반응** — 1~2턴 내 패닉 매도/매수는 대부분 손해. 다음날 반대 방향 30% 회복.
2. **수혜주는 따로 있다** — 악재라도 어떤 섹터엔 호재. 갈림길에서 누가 웃는가 본다.
3. **선반영 ≠ 발표** — 발표 시점엔 이미 끝. 발표 = 매도 신호인 경우가 더 많다.
4. **거래량이 진짜를 말한다** — 가격만 오르고 거래량 없으면 가짜. 항상 ▁▂▃ 막대를 본다.
5. **시간이 가장 강한 약** — 블랙스완도 평균 5~10일이면 안정화. 패닉 1턴, 관망 3턴.

## 🌊 파도 타기 마스터 체크리스트

각 이벤트를 마주할 때 30초 안에 점검:

```
□ 1. 이게 진짜 충격인가? (헤드라인 ≠ 충격)
□ 2. 누가 수혜고 누가 피해인가? (섹터 갈림길)
□ 3. 거래량은? (가짜 신호 필터)
□ 4. 첫 충격에 패닉할 가치가 있나? (대부분 No)
□ 5. 1주일 뒤 어디 있을까? (V자? 추세?)
```

이 5개를 매번 통과하면 평균 이상.
