# 차트 감각 시뮬레이션 — 게임 디자인 문서

> **컨셉**: 스타크래프트 한 판처럼, 한 번 앉으면 끝까지 몰두하게 되는 **1회성 차트 감각 훈련 게임**.
> 회원가입 없음. 한 판 = 15~25분. 끝나면 등급(S/A/B/C/D)과 리플레이.

---

## 1. 핵심 디자인 원칙

| 원칙 | 의미 |
|---|---|
| **One Match, One Story** | 한 판은 처음·중간·끝이 명확. 매번 다른 시드로 다른 시장. |
| **차트 감각 우선** | 뉴스·재무는 보조. 봉, 거래량, 추세선을 "느끼게" 만든다. |
| **결정의 무게** | 한 번의 매수가 판세를 바꿀 수 있다. 올인은 짜릿하고 위험하다. |
| **함정과 기회는 짝** | 모든 위기 뒤에 기회, 모든 호재 뒤에 함정. |
| **즉각 피드백** | 결정 직후 "왜 그런 결과인지" 차트 위에 표시. |

---

## 2. 한 판의 구조 — 3 Act

총 **66~75 결정**. 결정당 25~30초 → 약 **20분 한 판**.

```
Act 1 (탐색기)  ████░░░░░░░░░░░░  20일 / 22결정 / ~7분
Act 2 (격동기)  ░░░░██████░░░░░░  20일 / 26결정 / ~8분
Act 3 (결전기)  ░░░░░░░░░░██████  15일 / 22결정 / ~7분
                평온       흔들림    절정/결산
```

### Act 1 — 탐색기 (Discovery)

**목표**: 시장에 적응. 종목별 성격 파악. 첫 포지션 구축.

- 변동성 낮음(±1~2%/일)
- 명확한 추세선 표시 (가이드 ON)
- 5종목 중 2~3종목이 "조용히" 상승 추세 시작
- 함정 1~2개만 (가짜 돌파)
- **튜토리얼 힌트**: "거래량이 줄면서 가격만 오르면 의심하세요"

**미션**:
- [ ] 분산: 2종목 이상 매수
- [ ] 손절선 설정 (각 종목 -5%)
- [ ] 70% 이상 결정 시간 내 응답

### Act 2 — 격동기 (Turbulence)

**목표**: 함정을 피하고 대응 능력 시험.

- 변동성 급증(±3~7%/일)
- 갑작스러운 뉴스 5~7개 (진짜 3, 페이크 2~4)
- 가이드선 OFF (스스로 봐야 함)
- 한 종목은 **작전 패턴**(급등 → 급락) 확정 등장
- 한 종목은 **데드캣 바운스** 함정

**미션**:
- [ ] 손절 1회 이상 성공 (-5% 이내 컷)
- [ ] 가짜 돌파 1회 회피
- [ ] 현금 비중 30% 유지

### Act 3 — 결전기 (Showdown)

**목표**: 큰 사건에서 살아남고, 가능하면 역전.

- **블랙스완 이벤트** 1회 확정 (전체 -15~25% 갭하락 OR 특정 종목 +50% 폭등)
- 마지막 5결정은 "마감 베팅" — 시간 압박 강화 (15초)
- 모든 정보 노출, 차트 풀 가시화
- 결산 후 등급 산정

**미션**:
- [ ] 블랙스완 직전/직후 액션 (관망도 액션)
- [ ] 최종 +5% 이상 OR 자산 보존(-5% 이내)

## 3. 함정 시스템 — 차트의 거짓말 6종

각 함정은 시각적으로 알아볼 수 있는 **사전 신호**가 있다. 사전 신호를 학습하는 것이 게임의 핵심 학습 목표.

| # | 이름 | 차트 모습 | 사전 신호 | 걸리면 | 회피 보상 |
|---|---|---|---|---|---|
| 1 | **가짜 돌파** | 저항선 위로 살짝 튀고 다시 아래로 | 거래량 미증가 | -8~15% | +감각 +30 XP |
| 2 | **데드캣 바운스** | 폭락 후 +10% 반등 → 재폭락 | 음봉 사이 짧은 양봉 | -20~30% | +감각 +50 XP |
| 3 | **작전주** | 며칠간 점진 상승 → 갑자기 +30% → 다음날 -50% | 비정상 거래량 폭증 | -40~60% | +50 XP + 🎖️배지 |
| 4 | **호재 페이크** | "역대급 실적" 뉴스 → 차트는 하락 | 뉴스 직전 미리 상승 | -10% | +30 XP |
| 5 | **갭 하락** | 장 시작과 동시에 -8~12% | 전일 거래량 급증 + 음봉 | -10% (불가피) | 손절 시 +20 XP |
| 6 | **거래정지** | 정지 → 재개 시 가격 점프 | 직전 의심 가격 움직임 | -30% OR +30% | 회피 시 +40 XP |

**함정 노출 규칙**: Act 1은 1~2개(연습용), Act 2는 3~4개, Act 3는 1~2개 + 블랙스완.

## 4. 보상 시스템 — 차트 감각 점수

자산 수익률과 별개로 **차트 감각 점수(Sense Score)** 를 추적한다. 감각 점수가 등급(S/A/B/C/D)을 결정.

### Sense Score 가산

| 행동 | 점수 |
|---|---|
| 추세 시작점 매수 (저점 ±3% 이내) | +50 |
| 고점 매도 (고점 ±3% 이내) | +50 |
| 함정 회피 (위 표 참조) | +20~50 |
| 손절선 -5% 이내 컷 | +30 |
| 익절 +10% 이상 실현 | +30 |
| 30초 이내 결정 | +3 |
| 분산투자 유지 (3종목 이상) | +5/일 |
| 블랙스완 직전 현금화 | +100 |

### Sense Score 차감

| 행동 | 점수 |
|---|---|
| 함정에 걸림 | -30~80 |
| 고점 매수 / 저점 매도 | -40 |
| 손절 미실행 후 -10% 이상 손실 | -50 |
| 올인 후 -20% 이상 손실 | -100 |
| 타임아웃 | -5 |
| 5턴 이상 무거래 (관망 남발) | -20 |

### 등급 산정

```
S 등급: Sense ≥ 800 AND 자산 +20% 이상
A 등급: Sense ≥ 600 AND 자산 +10% 이상
B 등급: Sense ≥ 400 AND 자산 0% 이상
C 등급: Sense ≥ 200 OR  자산 -10% 이상
D 등급: 그 외
F 등급: 자산 -50% 이하 (게임오버)
```

## 5. 즉시 패배 조건 — Game Over

진짜 위기감을 만든다. 한 판이 절대 무사고로 흘러가지 않게.

- 자산 **-50% 이하** → 즉시 종료, F 등급
- 한 종목에 **자산 80% 이상** 투입 후 해당 종목 -30% → "올인 경고" 모달, 다음날도 -10% 추가 시 종료
- 타임아웃 **연속 5회** → "집중력 상실" 종료

게임오버는 **리플레이 버튼**과 함께 "이번 판에서 무엇이 잘못됐는지" 차트 위에 빨간 마커로 시각화.

## 6. 차트 감각 학습 장치

### 시각 가이드 (Act에 따라 단계적 OFF)

| 가이드 | Act 1 | Act 2 | Act 3 |
|---|---|---|---|
| 추세선 자동 그림 | ON | OFF | OFF |
| 지지/저항선 표시 | ON | ON (자동) | OFF |
| 거래량 막대 | ON | ON | ON |
| 이동평균선 5/20일 | ON | ON | ON |
| 봉 패턴 라벨 (망치/도지) | ON | OFF | OFF |
| 함정 사전경고 토스트 | ON | OFF | OFF |

### 결정 후 피드백

매 결정 직후 **3초 오버레이**:

```
✅ 좋은 매수 — 5일 이평선 돌파 직후 진입
   거래량도 평균 1.5배. 추세 신뢰도 78%
   +30 감각 점수
```

```
⚠️ 위험한 매수 — RSI 78 과매수 구간
   직전 음봉 2개 출현. 추세 약화 신호
   -20 감각 점수 (결과는 종가에 확정)
```

이 피드백이 곧 차트 감각 교육.

## 7. 종목 캐릭터 — 5종목 성격 분리

매 판 5종목은 다음 5가지 캐릭터 중 무작위 배정. **이름·로고는 가공**(예: 알파상사, 베타전자) 또는 실명을 쓰되 차트는 캐릭터에 따라 생성.

| 캐릭터 | 변동성 | 추세 | 함정 빈도 | 학습 포인트 |
|---|---|---|---|---|
| 🐢 **블루칩** | 낮음 (±1%) | 완만 상승 | 거의 없음 | 인내, 분산의 가치 |
| 🐂 **성장주** | 중간 (±3%) | 강한 상승 후 조정 | 가짜 돌파 자주 | 추세 추종, 익절 타이밍 |
| 🎢 **변동주** | 높음 (±5%) | 등락 반복 | 데드캣 자주 | 손절 규율 |
| 🦂 **작전주** | 매우 높음 (±8%) | 점진 상승 → 폭락 | 작전 패턴 확정 | 거래량 의심, 욕심 절제 |
| 💀 **부실주** | 중간 | 완만 하락 | 호재 페이크 | 가치 함정 식별 |

**한 판 구성 권장**: 블루칩 1, 성장 2, 변동 1, 작전/부실 1. 이 비율이 게임 난이도의 핵심.

## 9. 리플레이 — 학습 루프 닫기

게임 종료 후 "리플레이" 버튼:

- 모든 결정 시점에 **차트 위 마커**
  - 🟢 좋은 결정
  - 🔴 함정에 걸린 결정
  - 🟡 타이밍 아쉬움
- 마커 클릭 시 그 시점 차트 + 당시 보였어야 할 신호
- "이때 RSI가 80을 넘었어요. 매도 신호였습니다" 같은 사후 코칭

이게 진짜 차트 감각이 늘어나는 지점.

## 10. 데이터 모델 (localStorage)

회원가입 없이 단일 키로 운영. 한 판 = 1세션, 종료 후 결과만 누적.

```ts
// practiceProfile_v1
{
  totalRuns: number,
  bestGrade: "S" | "A" | "B" | "C" | "D" | "F",
  bestSenseScore: number,
  bestProfitRate: number,
  badges: string[],            // 영구 누적
  recentRuns: RunSummary[],    // 최근 10판
}

// 진행 중 한 판 (라운드 종료 시 삭제)
// currentRun_v1
{
  seed: number,                // 재현 가능
  act: 1 | 2 | 3,
  day: number, decision: number,
  cash: number, holdings: {...},
  senseScore: number,
  trapsHit: string[], trapsAvoided: string[],
  decisions: DecisionLog[],    // 리플레이용
}
```

이게 다임. DB 불필요.

## 11. 3티어는 "난이도 선택"으로 단순화

3개의 별개 기간이 아니라, **같은 한 판 구조에 난이도만 다르게**.

| 티어 | 시드 | Act 길이 | 함정 수 | 가이드 | 타이머 |
|---|---|---|---|---|---|
| 🌱 **튜토리얼** | 500만원 | 5/7/5일 (총 ~10분) | 2개 | 항상 ON | 30초 |
| ⚡ **표준** | 1,000만원 | 20/20/15일 (총 ~20분) | 5개 | Act 1만 ON | 30→15초 |
| 🏔️ **하드** | 1,000만원 | 25/30/20일 (총 ~25분) | 8개 + 블랙스완 2회 | 전부 OFF | 25→10초 |

**같은 게임, 다른 강도**. 클리어할수록 다음 티어 잠금 해제.

## 12. 구현 우선순위

1. **Act 구조 도입** — 시나리오 데이터를 3구간으로 메타 분리, Act 전환 트리거.
2. **함정 6종 구현** — 가격 시계열 생성기에 패턴 주입 (`utils/trapPatterns.ts` 신규).
3. **Sense Score 엔진** — 결정 평가 함수 (`lib/senseScore.ts`).
4. **결정 후 피드백 오버레이** — 기존 `CardFeedbackOverlay` 확장.
5. **결산/등급 화면** — 기존 `FinalGameReport` 확장.
6. **리플레이 모드** — 결정 로그 저장 + 마커 렌더.
7. **종목 캐릭터 5종 생성기** — 차트 데이터 생성 로직 분리.

> 당신의 차트 감각이 곧 점수다."
