## 0. 왜 글로벌인가

### 한국 개인투자자 현실 (2024~2025)

```
국내 시총 거래   ████████░░░  68%
해외 시총 거래   ████░░░░░░░  32%   ← 5년 전 8% → 현재 32%
서학개미 자산    1,200억$ ($150조)
```

**서학개미 트렌드**:
- 테슬라, 엔비디아, 애플은 한국 개인 보유 1~3위
- 미장 새벽 거래는 일상
- 코스피보다 나스닥 더 친숙한 20대도 다수

→ 한국만 다루는 시뮬은 **반쪽짜리**.

### 글로벌 확장의 학습 가치

| 학습 목표 | 글로벌 추가로 가능해짐 |
|---|---|
| 환율 영향 | KRW/USD 변동에 따른 평가손익 |
| 시차 거래 | 미국장 → 다음날 한국장 갭 |
| 분산 투자 | 한 시장 폭락에도 다른 시장 방어 |
| 상관관계 | NVDA → SK하이닉스 동조성 |
| ETF 활용 | 분산·레버리지·인버스 도구 |
| 글로벌 매크로 | 연준 결정 → 글로벌 동시 영향 |

## 5. 🌐 환율 시스템 — 게임의 새 변수

해외주를 도입하면 **환율(KRW/USD)** 이 핵심 변수가 됨.

### 환율 메커니즘

```ts
interface ExchangeRate {
  base: 1350           // 게임 시작 환율 (1$ = 1,350원)
  current: 1350        // 매 턴 갱신
  amplitude: 0.05      // ±5% 변동 가능
  trend: number        // 거시 이벤트에 따른 추세
}

// 해외주 평가 = (USD 가격 × 환율) / 시작 환율
// → 환율이 1350 → 1450 가면 자동 +7.4% 수익
```

### 환율 영향 이벤트 (기존 거시에 추가)

| 이벤트 | 환율 영향 | 학습 |
|---|---|---|
| 미 금리 인상 | $강세 (+3~5%) | 해외주 +수익 |
| 미 금리 인하 | $약세 (-3%) | 해외주 -수익 |
| 한국 정치 위기 (계엄) | $강세 (+5%) | 환차익 헤지 효과 |
| 글로벌 위험회피 | $강세 (안전자산) | 헤지 학습 |
| 한미 통화스왑 | $약세 | 위험 해소 |

### 환차손/환차익 학습 시나리오

```
시작:  TSLA 100주 × $250 × 1,350원 = 3,375만원
한국 정치 위기 → 환율 1,450원 (+7.4%)
TSLA 가격 그대로 = 3,625만원
                  → +250만원 환차익만으로!
```

→ **"국내 폭락 시 해외주가 환율로 방어"** 학습

### 게임 내 구현

```ts
function applyCorrelation(stocks: Stock[], turn: number) {
  for (const kr of stocks.filter(s => s.market === "KR")) {
    for (const us of CORRELATION[kr.id] || []) {
      const usPrev = stocks.find(s => s.id === us.id)?.priceHistory[turn-1]
      const usPrevPrev = stocks.find(s => s.id === us.id)?.priceHistory[turn-2]
      if (usPrev && usPrevPrev) {
        const usChange = (usPrev - usPrevPrev) / usPrevPrev
        kr.priceHistory[turn] *= 1 + usChange * us.strength * 0.5
      }
    }
  }
}
```
