# 현실감 있는 페이싱 — "매일 사건사고는 영화가 아니다"

> 스크린샷에서 본 "분기 실적 발표, 주가 이미 반영, +0.2%" — 이게 진짜 시장의 99% 모습.
> **매일 큰 사건이 터지면 그건 게임이 아니라 카지노다.**
> 이 문서는 이전 기획의 **이벤트 과다**를 바로잡고, 영화 같은 흐름을 설계한다.

---

## 0. 이전 기획의 문제 — Reality Check

### 이전: 너무 시끄러운 시장

```
Act 1 (20턴) 거시 5 + 미시 3 = 8 이벤트
Act 2 (20턴) 거시 7 + 미시 5 = 12 이벤트
Act 3 (15턴) 거시 2 + 블랙스완 1 + 미시 4 = 7 이벤트
─────────────────────────────────────────
55턴 / 27 이벤트 = 평균 2턴마다 이벤트 한 개
```

**문제**: 2턴마다 사건 → 차트가 사건 반응 그래프가 됨 → 진짜 차트 감각 못 키움.

### 실제 시장 현실 (2024년 KOSPI 기준)

```
1년 거래일 250일
├─ 시장 전체 ±2% 이상 움직인 날: 약 30일 (12%)
├─ 종목 ±5% 이상 움직인 날 (개별): 평균 종목당 15일 (6%)
├─ 진짜 "뉴스가 만든" 변동: 종목당 5~8회/년
└─ 나머지 200일: 그냥 잔물결 (±0.5%)
```

**진짜 시장 = 80% 잔잔, 15% 출렁, 5% 폭풍**

## 1. 새 페이싱 — "조용한 날이 대부분"

### 한 판 (55턴) 이벤트 예산 — **재조정**

```
┌──────────────────────────────────────────────────┐
│  Act 1 (20턴) — 거시 1~2 + 미시 1~2 = 2~4         │
│  Act 2 (20턴) — 거시 2~3 + 미시 2~3 = 4~6         │
│  Act 3 (15턴) — 거시 1 + 블랙스완 1 + 미시 1~2 = 3 │
│  ──────────────────────────────────────────────  │
│  총 9~13 이벤트 / 55턴  = 평균 5턴마다 1개         │
└──────────────────────────────────────────────────┘
```

> **줄였다 — 27개 → 11개 (60% 감축)**

### 턴별 분류

| 턴 유형 | 비율 | 화면 | 가격 변동 |
|---|---|---|---|
| 🟢 **조용한 날** | 70% | "어제 +0.2%, 시장 평이" | ±0.3~1% (노이즈) |
| 🟡 **소식 있는 날** | 20% | 마이너 뉴스 (이미 반영) | ±1~2% |
| 🟠 **출렁이는 날** | 8% | 미시 이벤트 발생 | ±3~6% |
| 🔴 **폭풍의 날** | 2% | 거시 이벤트 / 블랙스완 | ±5~15% |

### 비유

> **"영화는 클라이맥스가 1~2번이고 나머지는 빌드업이다."**
> 매 장면이 클라이맥스면 관객은 지친다. 게임도 마찬가지.

## 2. 뉴스 3단계 시스템

스크린샷의 핵심 관찰: 뉴스가 있어도 **"어제 발표 · 주가 이미 반영"** 이라고 명시 → 사용자가 헷갈려함.
이걸 게임에 적극 활용한다.

### 🔵 메이저 뉴스 (Major) — 진짜 가격 움직임

- 색깔: 빨강/파랑 강조
- 가격 즉시 ±3% 이상 반응
- 매수/매도 결정 가치 있음
- 빈도: **종목당 한 판에 0~2회**

```
🔴 [속보] SK하이닉스 분기 영업이익 +734% — HBM 슈퍼사이클
   거래량 평균 3배. 외국인 +1,200억 매수.
   → 시초가 +5% 갭상승
```

### 🟡 마이너 뉴스 (Minor) — 살짝 움직임

- 색깔: 주황
- 가격 ±1~2% 반응
- 결정 가치 미묘
- 빈도: **종목당 매 5~10턴 1회**

```
🟡 [공시] 삼성전자 자사주 매입 1조원 발표
   주주환원 강화 일환. 시장 컨센 부합.
   → +1.2% 정도, 거래량 평이
```

### ⚪ 노이즈 뉴스 (Noise) — 의미 없음 / 함정

- 색깔: 회색
- 가격에 영향 없거나 **선반영**
- "이미 반영" / "관망" 표시
- 빈도: **매 턴 30% 확률**
- **함정**: 진짜처럼 보이지만 매수하면 -손실

```
⚪ [실적] 분기 실적 시장 예상치 하회, 전망 하향
   매출 성장 둔화, 수익성 약화 전망
   ⚡ 어제 발표 · 주가 이미 반영
   → 가격 변동 미미 (±0.3%)
```

```
⚪ [루머] OO 인수설 보도
   회사 측 "사실 무근" 공시
   → 함정: 매수 시 다음 턴 -3%
```

### 화면 구현 (스크린샷 참고)

```
┌──────────────────────────────────┐
│ 📰 시장 뉴스               [상승세] │
│ 분기 실적 시장 예상치 하회         │
│ 전망 하향                  09:15  │
│ 매출 성장 둔화, 수익성 약화 전망   │
│ ⚡ 어제 발표 · 주가 이미 반영      │ ← 회색 뱃지
└──────────────────────────────────┘
```

이 "이미 반영" 뱃지가 **노이즈 vs 메이저** 구분의 핵심 학습 도구.

## 3. 하루 안의 흐름 — Intraday 패턴

스크린샷에서 본 시간 표기: **16:00, 09:00, 10:30, 12:00, 14:00**

```
16:00 (전일 종가) → 09:00 (시초가) → 10:30 → 12:00 → 14:00 → 15:30 (종가)
```

### 1턴 = 1결정 시점

표준 모드 기준: **하루 2턴** (09:00 시초, 14:00 마감 직전)

```
하루 흐름:
  16:00 ─→ 09:00      → 결정 1 (아침)
              │
              ▼
           10:30  ─→ 12:00 ─→ 14:00 → 결정 2 (오후)
                                  │
                                  ▼
                               15:30 (종가)
```

### Intraday 패턴 (조용한 날의 예시)

```
시간     가격    변동     이유
09:00   72,500  +0.2%   시초 갭업 (전일 미장 영향)
10:30   72,400  -0.1%   장중 매도세
12:00   72,200  -0.3%   점심시간 거래 감소
14:00   72,500  +0.4%   기관 매수 유입
15:30   72,610  +0.2%   종가
```

→ 차트 모양: `▆▅▄▅▇` (스크린샷처럼 잔물결)

### Intraday 패턴 (메이저 뉴스 날)

```
09:00   75,000  +5.0%   시초 갭업 (HBM 호재)
10:30   76,500  +2.0%   추격 매수
12:00   76,200  -0.4%   차익실현
14:00   76,800  +0.8%   외국인 추가 매수
15:30   77,000  +0.3%   종가
```

→ 차트 모양: `▁▆█▇█` (확연한 폭등)

이 두 패턴이 **눈에 보이게 다르게** 그려져야 사용자가 차트만 봐도 "오늘은 뭔가 있다" 느낌.

## 4. 주(週) 단위 리듬

스크린샷의 "1주차" 표기 — 게임은 **주 단위 리듬**으로 흘러간다.

### 1주 = 5거래일 = 10턴 (하루 2결정)

각 주마다 **한 가지 메인 테마**가 있어야 영화처럼 보인다.

```
1주차: "잔잔한 시작" (Act 1 도입)
   - 메이저 0, 마이너 1, 노이즈 다수
   - 가격: ±2% 이내
   - 학습: 차트 보는 법, UI 적응

2주차: "첫 시그널" (Act 1 후반)
   - 메이저 1 (예: 어닝 서프), 마이너 1
   - 가격: ±5% 이내
   - 학습: 첫 매수 손맛

3주차: "흔들림 시작" (Act 2 초반)
   - 메이저 1~2, 마이너 2
   - 가격: ±7% 이내
   - 학습: 함정 첫 노출

4주차: "격랑" (Act 2 후반)
   - 메이저 2, 미시 함정 1, 노이즈 다수
   - 가격: ±10% 이내
   - 학습: 손절 규율

5~6주차: "결전" (Act 3, 블랙스완)
   - 블랙스완 1, 메이저 1
   - 가격: ±15% (한 번에 -8% 갭)
   - 학습: 패닉 대응
```

### 6주 = 30거래일 = 60턴 (표준 모드 한 판)

이 리듬이면 **2주에 한 번 큰 사건** = 진짜 시장 감각.
