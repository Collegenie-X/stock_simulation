# 개별 종목 이벤트 50선 — Micro Events

> 거시 이벤트(전쟁·계엄·금리)는 [GAME_REAL_EVENTS_50.md](GAME_REAL_EVENTS_50.md) 에.
> **이 문서는 개별 회사에 일어나는 50가지 사건** — 실적·신제품·임상·사고·M&A·루머.
> 거시는 시장 전체를 흔들지만, 미시는 5종목 중 1~2종목만 흔든다.

---

## 0. 왜 개별 이벤트가 필요한가

```
거시 이벤트만:    모든 종목이 같은 방향으로 움직임 → 분산 무의미
미시 이벤트 추가:  같은 시장 안에서 종목별 차별화 → 종목 선별 학습
```

**예시**: 블랙스완(계엄)이 와도 셀트리온은 임상 성공 발표로 +5%, 동시에 카카오는 압수수색으로 -10%.
이게 진짜 시장의 모습.

### 학습 가치

| 학습 목표 | 미시 이벤트 역할 |
|---|---|
| 어닝 시즌 사고 | 분기마다 실적 발표 시뮬 |
| 호재 페이크 | 발표 ≠ 매수 시점 학습 |
| 작전주 식별 | 루머 + 비정상 거래량 패턴 |
| 손절 규율 | 어닝쇼크/리콜 시 즉시 컷 |
| 수급 읽기 | 외국인·기관·공매도 신호 |

## 4. 한 판 통합 시나리오 빌드 — Macro × Micro

### 60턴 한 판의 이벤트 예산

```
┌─────────────────────────────────────────────────────┐
│            한 판 = 거시 14 + 미시 12 = 28 이벤트     │
├─────────────────────────────────────────────────────┤
│  Act 1 (1~20턴)  거시 5 + 미시 3 = 8                 │
│  Act 2 (21~40턴) 거시 7 + 미시 5 = 12                │
│  Act 3 (41~55턴) 거시 2 + 블랙스완 1 + 미시 4 = 7    │
└─────────────────────────────────────────────────────┘
```

### 미시 이벤트 분배 규칙

```ts
function distributeMicroEvents(stocks: Stock[], totalMicro: number) {
  // 1. 종목당 평균 2~3개 미시 이벤트
  // 2. 캐릭터에 맞는 이벤트만 추출 (위 매트릭스 참조)
  // 3. 작전주는 반드시 M22 또는 M47 또는 M48 1개 이상 (함정 강제)
  // 4. 부실주는 반드시 M02·M07·M37·M38 중 1개 이상
  // 5. 시점 분산 (같은 종목 연속 X)

  const result: ScheduledEvent[] = []
  for (const stock of stocks) {
    const eventPool = MICRO_EVENTS.filter(e => e.charAffinity[stock.character] >= "rare")
    const count = stock.character === "trap" ? 3 : 2  // 작전주는 더 많이
    const events = pickN(eventPool, count, weightByAffinity)
    for (const e of events) {
      result.push({
        eventId: e.id,
        stockId: stock.id,
        triggerTurn: pickRandomTurn(spread=true),
      })
    }
  }
  return result
}
```

### 시점 배치 — 자연스러운 흐름

```
턴   1    5    10   15   20  | 21  25   30   35   40 | 41  45   50   55
────────────────────────────────────────────────────────────────────────
거시      ●         ●        |  ●       ●        ●   |       🔥
종A 블루       △          ★  |          △            |       △
종B 성장  △            ★    |               △       |  ★
종C 변동       △       △    |   △       △           |       △
종D 변동                     |       △        △      |  △
종E 작전            ★        |   ⚠️                   |       💥(폭락)

● 거시 이벤트   △ 미시 호재/중립   ★ 미시 큰 사건   ⚠️ 루머   💥 함정 발동
```

### 거시 × 미시 충돌 규칙

같은 턴에 거시 + 미시가 겹치면:
- **방향 일치**: 효과 합산 (단, 최대 ±15% 클램프)
- **방향 반대**: 합산 → 학습 포인트 ("악재 속 호재 종목")
- **미시가 거시를 덮을 수 있는가?**: 큰 미시(M20 FDA, M27 피인수)는 거시 약세를 뚫고 +상승 가능

## 8. 데이터 스키마 — 미시 이벤트 객체

```ts
interface MicroEvent {
  id: string                    // "M01"
  category: "earnings" | "product" | "contract" | "clinical" | "ma" |
            "shareholder" | "incident" | "supply" | "rumor"
  title: string                 // "어닝 서프라이즈"
  headline: string              // "[속보] OO 분기 영업이익 컨센 +47% 상회"
  body: string                  // 본문 2줄
  source: string                // "전자공시"

  magnitude: number             // 기준 변동률 ±0.05 = ±5%
  peakOffset: number            // 피크까지 N턴
  aftermathLen: number          // 잔향
  aftermathRate: number         // 잔향 방향 (트랩이면 음수)

  characterAffinity: {          // 캐릭터별 발생 가중치 (0~3)
    bluechip: 0 | 1 | 2 | 3
    growth: 0 | 1 | 2 | 3
    volatile: 0 | 1 | 2 | 3
    trap: 0 | 1 | 2 | 3
    decline: 0 | 1 | 2 | 3
  }

  preSignal?: {                 // 사전 신호 (학습용)
    type: "volume" | "foreign" | "rumor" | "consensus"
    description: string
  }

  isFakeable: boolean           // 함정 가능성 (호재 페이크 등)
  realCase?: string             // 실제 케이스 텍스트

  learningTags: string[]        // ["earning_surprise", "volume_skepticism"]
}
```
