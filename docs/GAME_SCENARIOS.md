> Act당 20개씩 풀(pool) 보유 → 매 판 무작위로 N개 추출 → 시계열 가격에 파도(wave)로 주입.

## 0. 파도(Wave) 생성 원리

가격은 단순 랜덤이 아니라 **3개 레이어 합성**:

```
최종 가격 = 베이스 추세(완만한 사인파) + 노이즈(±0.5%) + 이벤트 스파이크
```

### 레이어 1 — 베이스 추세 (Sine Wave)

```ts
basePrice(t) = initial * (1 + amplitude * sin(2π * t / period + phase))
// amplitude 0.05~0.15, period 15~30턴, phase 랜덤
```

종목별로 다른 진폭/주기 → 어떤 종목은 상승 추세, 어떤 종목은 횡보, 어떤 종목은 하락.

### 레이어 2 — 노이즈

```ts
noise(t) = price * (Math.random() - 0.5) * 0.01  // ±0.5%
```

차트에 자연스러운 "잔물결".

### 레이어 3 — 이벤트 스파이크

Act별로 N개 이벤트가 랜덤 시점에 트리거. 각 이벤트는 **시작 → 피크 → 잔향** 3단계로 가격을 흔든다.

```ts
eventImpact(t, event) =
  if t < event.startDay: 0
  if t < event.peakDay: linearInterp(0, event.magnitude, ...)
  if t < event.endDay:  linearInterp(event.magnitude, event.aftermath, ...)
  else: event.aftermath
```

### 파도 합성 예시

```
Act 1 (낮은 진폭)        : ▁▂▃▄▃▂▁▂▃▄▃▂▁  ±2%
Act 2 (이벤트 다발)      : ▁▂▆█▃▂▇█▃▂▁▆█  ±7%
Act 3 (블랙스완)         : ▁▂▃▄▂▁▁▁▁█▇▆▅  ±20% 한 방
```

## 4. 매판 시나리오 빌드 알고리즘

```ts
function buildScenario(seed: number): GameScenario {
  const rng = seedRandom(seed)

  // 1. 종목 5개 캐릭터 배정 (블루칩1 / 성장2 / 변동1 / 작전or부실1)
  const stocks = pickStocks(rng, [BLUECHIP, GROWTH, GROWTH, VOLATILE, TRAP])

  // 2. 각 종목 베이스 추세 생성 (서로 다른 진폭/주기)
  for (const s of stocks) {
    s.baseSeries = generateSineWave(s, rng)
  }

  // 3. Act별 이벤트 추출
  const act1Events = pickN(ACT1_POOL, 5, rng)        // 5개 (4~6 중)
  const act2Events = pickN(ACT2_POOL, 7, rng, {
    mustInclude: ["trap"],                            // 함정 최소 2
    minTraps: 2,
  })
  const act3Events = pickN(ACT3_POOL, 2, rng, {
    mustInclude: ["blackswan"],                       // 블랙스완 1 확정
  })

  // 4. 이벤트를 시계열에 주입 (랜덤 시점)
  applyEventsToTimeline(stocks, act1Events, day=0..20)
  applyEventsToTimeline(stocks, act2Events, day=20..40)
  applyEventsToTimeline(stocks, act3Events, day=40..55)

  // 5. 노이즈 + 봉 패턴 후처리
  for (const s of stocks) {
    addNoise(s.series)
    injectCandlePatterns(s.series)  // 망치형, 도지 등
  }

  return { stocks, events: [...act1Events, ...act2Events, ...act3Events], seed }
}
```

### 이벤트 주입 함수

```ts
function applyEvent(series: number[], event: Event, startDay: number) {
  const peakDay = startDay + event.peakOffset      // 보통 1~3턴 후
  const endDay = peakDay + event.aftermathLen      // 잔향 길이

  for (let t = startDay; t < endDay; t++) {
    const phase =
      t < peakDay
        ? (t - startDay) / (peakDay - startDay)    // 0→1 상승
        : 1 - (t - peakDay) / (endDay - peakDay)   // 1→0 감쇠
    series[t] *= 1 + event.magnitude * phase
  }

  // 함정형은 잔향이 반대 방향
  if (event.type === "trap") {
    for (let t = endDay; t < endDay + 3; t++) {
      series[t] *= 1 + event.aftermath  // 보통 -magnitude*0.7
    }
  }
}
```

## 6. 뉴스 텍스트 시스템

각 이벤트는 게임 중 **헤드라인 + 본문 2줄 + 출처**로 표시. 함정형은 **진짜처럼 그럴듯하게** 작성하는 것이 중요.

```ts

  id: "A2-11",

  source: "한국경제 · 2025.01.15",
  isReal: true,        // 뉴스 자체는 진짜
  isFakeSignal: true,  // 하지만 차트는 이미 선반영 → 함정
}
```

플레이어는 뉴스만 보면 매수, 차트(이미 +5% 갭)를 봐야 함정 인지.
